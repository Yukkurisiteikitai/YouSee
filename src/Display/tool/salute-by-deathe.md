# いつか死にゆく者より敬礼を

私、佐藤健太郎は肝臓がんステージⅣと診断された。医師の言葉は冷たく、生存率3.5%という数字だけが頭から離れなかった。それでも、ほんのわずかな希望がある限り諦めたくない。

二週間後には手術を受ける予定だ。生死の境をさまよう日々が始まる。その中で、私は一つの決意を固めた。「やり残したことを全て片付ける」。それは自分のためでもあり、家族のためにもあった。

最初に思い浮かんだのは、母への感謝の言葉だった。親孝行が足りなかったと後悔していた私にとって、これが最後の機会かもしれない。私は病院から家へ電話をかけた。「お母さん、今度はちゃんと話すから、待ってて」と伝えた。

翌日、家族全員に呼び出された。父も兄も妹も揃い、皆が私の話を待っている。私は深呼吸をして口を開いた。「今まで親孝行ができなくてごめん。でも、これから少しでも恩返しできるように頑張るから」と言った。母は泣きながら笑顔で「お前がそう思ってくれてるだけで十分だよ」と答えた。

次に思い浮かんだのは、友人への感謝の言葉だった。私は彼ら全員に手紙を書いた。「君たちと過ごした時間は最高だった。これからも幸せに生きていってね」というメッセージを込めて。それぞれの思い出やエピソードを書き連ねた手紙は、私の心の中にある大切な感情を形にするものとなった。

友人の一人である田中さんには、「高校時代のあの夏祭りでの騒ぎは最高だったね。君がいなければ、僕の青春も半分しかなかったと思う」と書いた。もう一人の山本さんには、「大学時代に一緒に起した夜中のラーメン屋巡り、本当に楽しかったよ。またいつか一緒にやろう」と伝えた。

そして最後に、自分の人生について考えた。やり残したこと、後悔することなく生きてきたか。その答えを見つけ出すためには、自分が何を大切にしてきたのかを再確認する必要があった。私は昔の日記や写真を見返し、思い出を振り返った。それらは私自身の成長と変化を物語っていた。

ある日の夕方、病室で窓から見える街の景色を見ながら、私は一人で考えた。「もしも生き延びることができたら、何をしたいか？」その答えはすぐに見つかった。「家族や友人と過ごす時間を大切にすること」。そして、「自分の人生を後悔なく生きていくこと」。

二週間の間に、私は多くのことを成し遂げた。家族との絆を深め、友人への感謝を伝え、自分の人生を見つめ直した。

ある日、父と二人で病室にいたときのことだ。「お前が子供の頃、よく一緒に釣りに行ったね」と父が言った。私は微笑んで、「そうだな。あの時の思い出は一生忘れないよ」と答えた。その言葉をきっかけに、私たちは昔の話をしながら笑い合った。

また、妹と二人で病室で過ごしたときには、「お前が小学生の頃、よく一緒に遊んだよね」と話すと、妹も「うん、楽しかったな」と微笑んでくれた。その瞬間、家族との絆を再確認し、感謝の気持ちが溢れた。

そして友人たちへの手紙は、それぞれに丁寧に封筒に入れて郵便局から送った。「君たちと過ごした時間は最高だった。これからも幸せに生きていってね」というメッセージを込めて。

二週間という短い期間でも、私は多くのことを成し遂げた。家族との絆を深め、友人への感謝を伝え、自分の人生を見つめ直した。そして手術の日が来たとき、私は心に余裕を持っていた。

「いつか死にゆく者より敬礼を」という言葉は、私の決意表明でもあった。生きる希望と、やり残したことなく生きていくという意志を込めて。

手術当日、家族や友人が病院に駆けつけた。父の目には涙が浮かんでいた。「頑張れよ」と声をかけられると、私は笑顔で「ありがとう」と返した。そして、医師たちと共に手術室へと向かった。

手術は長時間に及んだ。家族や友人は待合室で祈り続けた。手術が終わり、医師が出てきたとき、全員の心臓が止まるかと思った。「無事に終了しました」という言葉を聞いた瞬間、皆の目から涙が溢れた。

私は意識を取り戻したとき、病室で家族と友人が待っていた。彼らの顔を見た瞬間、胸が熱くなった。「ありがとう」と口に出すことができた。

その後の回復期も長かったが、家族や医療スタッフの支えがあり、少しずつ元気を取り戻していった。手術から半年後には退院し、再び日常に戻ることができた。

「いつか死にゆく者より敬礼を」という言葉は、私の人生の転換点となった。生きる希望と、やり残したことなく生きていくという意志を込めて、これからも前向きに生きていきたいと思う。
